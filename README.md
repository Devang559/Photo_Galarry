# Photo Gallery

A React + Vite photo gallery app styled with Tailwind CSS.

## Features

- Fetches 30 photos on load
- Responsive grid layout
- Real-time search by author name
- Favourites managed with useReducer
- Favourites persisted in localStorage
- Custom useFetchPhotos hook
- useCallback and useMemo optimizations

## Getting Started

`ash
npm install
npm run dev
`
